# Complete captured rescale execution

[SOURCE] The approved smaller Lean relation is unchanged from
`../rescale_compiler_successor/artifacts/template_ir2.json`: 24,575 trace
columns, 32,043 arithmetic constraints, and ExactPublic table 11 with 88 columns.
It describes the captured native directed 9-to-4 RNS scaler for the real
nonlinear degree-8192 operator. The fixed public tuple uses radix 512, with
four output limbs beginning at column 64.

[DERIVED] Six chunks of 4,096 rows partition all 24,576 component/coefficient
positions. Global row ID is `component * 8192 + coefficient`; no position is
sampled, duplicated, or padded. The reader reconstructs each tuple from the
same complete capture and checks all 98,304 output residues against the raw
output ciphertext using public library decoding and inverse NTT.

The single authorized sequence uses one native witness emission, one proof
invocation, and one fresh-process verification per chunk, sequentially. The
proof invocation also verifies its result with a fresh backend configuration.
Witness generation is untrusted: the executable does not construct AIR, and
the template must equal the approved Lean-generated bytes. Four Rayon threads
and the frozen portable public-preprocessing backend retain the predecessor's
proof parameters and private-witness randomness behavior.

Each step records its command, UTC interval, exit status, elapsed time and
resource usage. A failure or timeout stops the sequence with its artifacts
retained; no retry is part of this run. Source, template, native program and
case pins are checked before launch and after completion. All six independent
proofs must verify against the same source capture and output ciphertext.

Raw witnesses live under ignored `work/`, are compressed after verification,
and are removed only after successful compression with raw and compressed
hashes retained. Compressed witnesses remain local ignored transport, while
public cases, proofs and verification records are retained as normal results.
No private key, plaintext, decryption or new BFV operation is needed.

The resulting proof scope is the **complete captured rescale**. It does not
prove extension/convolution, the capture program, Rust parsing/serialization,
NTT conversion, whole ciphertext multiplication, BFV noise/security, or a
query authorization protocol. Post-run reporting only aggregates retained
public results and provenance. No extra negative grid or baseline reproof is
included.
