## 2. The vector function and the counted queries are the actual ones

[SOURCE / construction] [2014/917](https://eprint.iacr.org/2014/917), §4 pp.12–14, explicitly assumes multi-bit NCFE or suggests issuing a key per output bit. Its real branch returns the entire randomized encoding `RE.Encode(F,x;PRF_KP(tau))`; the alternate branch returns a symmetric decryption of the programmed ciphertext. The source's public-key extension is stated to be essentially identical. The displayed public variant in the target is a valid direct substitution under its explicit `NC-MO_Q` premise: no new secret is required by public encryption, and one vector G key is issued for one final F key.

[DERIVED / parameter substitution] The new encrypted input has width `n+O(kappa)`. If `M` and the shallow G circuit size are polynomial in the public target bounds, then an output-independent bound `poly(kappa,n,Q,log S_G)` yields `poly(kappa,n,Q,log S)`. Long G keys, programmed ciphertexts and decoding outputs may be charged outside encryption. A backend whose encryption cost itself depends on M does not satisfy this implication simply because F's final answer is Boolean.

[DERIVED / public proof normalization] For a static function/message tuple, the tags, PRF keys, symmetric keys and programmed vector values can be fixed before the current NCFE setup in the corresponding reduction. At the FE switch, equality is equality of the whole vector. Use the common alternate-branch message `(0,0,KE,1)`: G ignores x and KP when its branch bit is one. The printed ABSV proof instead retains m0 in an inactive input field and later calls the final hybrid independent of the challenge message. Choosing zero at the original switch makes that statement exact without adding a hop. This normalization was also recognized in the predecessor base-FE review. No numerical QA coefficient is asserted by the new note, and none is certified here.

[SOURCE / construction and bounded-query theorem] [2014/148](https://eprint.iacr.org/2014/148), Appendix D pp.35–38, uses an arbitrary-output circuit-FE function that emits the garbled program and input, or a vector pad. Footnote 15 limits its Boolean/vector equivalence by separate keys to the unbounded-key setting. Theorem D.3 counts one circuit-function query per RAM-function query. Its §D.3 encryption analysis assumes the starting circuit FE has the stated input-linear polynomial cost. The later bitwise key optimization does not preserve that query count when implemented by a bounded-key Boolean backend.

[DERIVED / arity, not a universal lower bound] The literal bit-splitting algorithm issues Q*M Boolean function-key queries to one backend instance. A tuple called one application key still exposes all those underlying tokens. These are counts of the inspected wrapper's calls, with a worst-case supported bound; they are not a theorem that every specialized encoding has Q*M distinct semantic predicates or that no other construction can compress them. Deduplicating coincident functions or replacing the primitive would need its own interface analysis.

## 3. The GVW M-power calculation is correct and separately scoped

[DERIVED] Substitution of `q=Q*M` therefore gives

```text
N = Theta(kappa*D^2*Q^4*M^4),
S_share = Theta(kappa*Q^2*M^2).
```

[DERIVED] This is already M-dependent before counting share construction, increased message widths, field-bit representations and base encryption work. The M powers are exact normalized monomial substitutions, not exact implementation ratios with unspecified Theta constants, and not a lower bound on all bounded-key FE. The finite ledger keeps that distinction.

[SOURCE / separate statement] [2012/733](https://eprint.iacr.org/2012/733), Corollaries 3.4–3.5 and Remarks 3.6–3.7, pp.22–23, states its q and q*k expansions separately, distinguishes ABE many-key security from FE single-key security, and discusses the repeated-output chaining cost. [DERIVED / field-output qualification] The GVW function `G_C,Delta` emits a field element, so a Boolean backend must support the corresponding b output bits or another matching field interface. For a literal b-bit chunk wrapper, `b*ceil(M/b)>=M`; changing labels from bits to field elements does not remove the emitted-output cost. The note explicitly preserves this source-interface obligation.

## 4. AJ's loop relocation is substantive, with exact normalization

[SOURCE / constructor] AJ [2015/173](https://eprint.iacr.org/2015/173), §8 pp.44–47 and Theorem 9, really constructs compact FE from semi-compact FE and a compact TMRE primitive. The latter's encoding work is polynomial in security parameter, program length, input length and log execution bound. The setup public key is a compact encoding of a loop producing all M underlying public keys. Encryption compactly encodes a loop which decodes that public key and produces all M underlying ciphertexts. The full loop executes during decoding. This is different from executing M encryptions and merely calling the resulting tuple succinct.

[DERIVED / instance distribution] There are M separately addressed SCFE instances. Each receives Q function-key queries when Q outer functions are authorized. Real setup tapes are `P_Ks(i)` under a common seed, and encryption tapes likewise share a fresh seed Ke. Those tapes are not jointly uniform independent strings in the real construction. The source's puncturable-PRF hybrids make a selected index's tapes uniform before invoking the corresponding fresh SCFE game. Off-index tapes remain locally generatable from punctured keys. Thus the query count Q per selected instance is valid, while the target's phrase “M independent SCFE instances” must be read as separate instance identities rather than a statistical-independence assertion.

[SOURCE / proof and omitted figure arguments] Appendix B pp.53–56 uses index-by-index puncturing, tape replacement, one selected SCFE switch and reversal. The source figures omit PRF tape arguments in setup and omit the explicit selected-index insertion in their punctured forms; some branch/figure references are also abbreviated. The target rightly supplies the required same-tape and selected-index rules. Acceptance is of these stated completed algorithms, not literal execution of the abbreviated figures.

[DERIVED / same-machine and time requirement] Section 8.1 p.45 requires equal input length, equal output and **equal actual machine runtime** for its same-machine IND comparison. Encoding a fixed universal machine on two padded program descriptions handles the differing source programs only after all these premises are enforced. Use a clocked universal interpreter which simulates either padded program for the same public step budget, records its bounded output, and continues with dummy work after halt. Equal public output widths and a fixed final write stage give a common actual runtime. A shared upper bound T alone is insufficient.

[DERIVED / compactness after normalization] The one-index punctured program contains one SCFE public key or ciphertext and a punctured PRF key, rather than M such objects. Under the stipulated semi-compact and uniformly efficient interfaces these program/input widths are polynomial in kappa, n, Q and logarithmic public size metadata. Choose one fixed padded width for all compared programs/inputs at the same public bounds. Clocking may cost polynomial execution work, but compact TMRE encoding sees only the logarithm of that common bound. It therefore preserves the proposed encryption bound; setup and decoding still pay their full polynomial-in-M work. This is exactly where the new time-compressing primitive is used.

[SOURCE / definition normalization] The displayed §8.1 p.45 success-probability formula, in both the pinned text and a fresh raw extraction, writes `Pr[b'=b]<=negl(kappa)`. Read literally that is violated by an independent fair guess. Its surrounding indistinguishability prose supplies the intended ordinary advantage bound over one half. The conditional contract must use that standard definition, not the malformed displayed success bound. This is a source notation correction, not a refutation of its intended theorem.

[DERIVED / QA stopping point] For fixed classical external functions/messages, the completed hybrids are a plausible straight-line QA reduction: one selected SCFE instance receives Q queries; other instances and encodings are generated by classical postprocessing; the continuing quantum distinguisher is called once. The appropriate QA TMRE, puncturable-PRF and Q-key SCFE games must actually be assumed or proved, with common resource envelopes and their quantitative losses. The index-by-index proof and any nonperfect correctness union must retain M-dependent losses. The target explicitly leaves that full bookkeeping open; this review does not upgrade a candidate QA lift to an instantiated theorem.
