# Archive — superseded working files

These are **history, not truth.** Each contained claims later refuted,
narrowed, or restated; the corrections are folded into `docs/VERDICTS.md`,
which is the single current-truth file. Kept because the *reasoning* and the
measurements are still evidence, and because a refuted claim with its
refutation attached is how we avoid re-deriving it.

**Do not cite these files. Cite `docs/VERDICTS.md`, or the lane note that
produced a measurement.**
