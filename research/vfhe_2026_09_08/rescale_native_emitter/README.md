## How the plan is obtained

[EXECUTED] `Compiler/RescaleWitnessPlan.lean` reuses the frozen query witness plan's `Builder`, `Operand`, `compute`, `put`, and `input`. The actual register base is overridden with the smaller rescale width. Large literal operands are serialized as decimal strings instead of machine integers. The native executor uses checked i128 arithmetic when possible, promotes exactly to BigInt on overflow, and returns to i128 when a result fits. Positive-denominator division and remainder follow Euclidean integer semantics.

[DERIVED] Scalar generation is source-driven. `knownPart` reads the actual `SignedMatrix.Row` constant and coefficients, refusing an unassigned non-pivot variable. `solveSingle` eliminates a unit-coefficient unknown. `solveQR` reads the divisor from a negative quotient coefficient and requires remainder coefficient-1; it computes the quotient/remainder witness. `scalarValues` orders those solves using the existing directed RNS frontend's input, Garner, directed correction, shared-Y and target-projection rows. It does not copy the native scaler formula into Rust or author a second rescale AIR.

[EXECUTED] After scalar elimination, the emitter reuses `ProfiledWitness.caches` and the frozen `SideCache` layout to lower sparse column masses, carries, digits and bits to generic instructions. Public aliases become equality assertions, preserving all88 caller columns including global row IDs.
