# Three small explanations

These are explanatory models, explicitly labeled as such. They must not simulate a completed privacy claim.

1. **Teach → change → answer.** Three keyboard-operable buttons advance a tiny visible integer learner alongside its opaque ciphertext state. Reveal the reference only through a separate “research reader” control. Caption: the completed experiment retains this reader; removing its unrestricted power is unfinished.

2. **Which answer can this key reach?** Select full reader, fixed-span credentials or the proposed exact-release capability. Highlight reachable cells in a small history × query grid. Retained old states remain reachable under surviving credentials. Mark the exact-release setting as a target construction, not an implemented guarantee.

3. **Copy yesterday.** Fork a state into two correctly computed futures. Both receive computation checkmarks. Selecting an accepted history changes which release is authorized, illustrating the additional continuity requirement. Explain that a local journal's choice is not automatically cryptographic protection against a malicious host.

Use real text, visible focus, reduced-motion support and a static caption that preserves each explanation without JavaScript.
