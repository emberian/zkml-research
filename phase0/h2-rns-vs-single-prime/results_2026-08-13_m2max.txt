# H2 measurement: 3-limb RNS (36/36/37) vs single 109-bit prime, and the proof-field cost
# host: Apple M2 Max, 12 core, arm64, macOS. rustc release, lto=fat, codegen-units=1.
# CONTENDED BOX (load avg 78 during the run: co-tenant lake/Lean builds).
# Each figure is min-of-40-trials x 60..800 iters; ratios stable to ~5% across 3 whole-program runs.
# Reproduce: cargo run --release   (in this directory)
#
# validation gates run at startup, all pass:
#  - fhe-math 0.1.1 NttOperator and our Ntt64 both convolve negacyclically vs schoolbook (n=8)
#  - forward/backward round trip at N=4096 for q0(36b), p61(61b), p109 Solinas, p109 generic
#  - our u128 NTT negacyclic convolution vs schoolbook (n=8)
#  - fhe-math's own NttOperator is timed alongside ours so the u64 baseline is not a strawman
