## Exact semantic event and efficient observed event

[SOURCE] `BinaryMerkle.HashSuite`, `cubeRoot`, `recompute`, `openingScheme`, and `accepted_different_values_imply_collision` appear in [BinaryMerkle.lean](/Users/ember/dev/minidregg/Selvage/BinaryMerkle.lean:27), respectively at lines 27, 50, 73, 134, and 257. Paths contain arbitrary sibling digests; their length is checked, but sibling preimages are not. Paths and address bits run top-down; recomputation recurses to the leaf and hashes bottom-up. [OpeningResolution.lean](../formal/full_ud_commitment_timing/src/Selvage/OpeningResolution.lean:18) defines `DoubleOpening` by existence of an index, two unequal values, and two accepted paths. Its `word` uses `Classical.choose`; no efficient observation of that second path follows.

[DERIVED] Set `a=L(v0)`, `b=L(v1)`, and `rt=H(a,a)`, where `L:{v0,v1}→D` and `H:D²→D` are independent uniform functions and `|D|=N≥2`. The honest word `(v0,v0)` opens at either index. At index zero, an unequal opening exists exactly when some `H(b,s)=rt`; at index one it exists exactly when some `H(s,b)=rt`. Conditional on `a≠b`, the first event tests `N` independent inputs and the union tests `2N−1`, all disjoint from `(a,a)`. Conditional on `a=b`, both events hold. Therefore:

| Event | Exact probability | N=2 | N=3 |
| --- | --- | --- | --- |
| Fixed index-zero ambiguity | `1−(1−1/N)^(N+1)` | `56/64=7/8` | `142155/177147=65/81` |
| Literal `DoubleOpening` at either index | `1−(1−1/N)^(2N)` | `60/64=15/16` | `161595/177147=665/729` |
| Observed conflict in the supplied singleton transcript | `0` | `0` | `0` |

[EXECUTED] Independently enumerated all 64 and 177,147 complete function tables with [controls.py](controls.py); [RESULTS.json](RESULTS.json) matches both corrected formulas. The full event approaches `1−e^-2`. With a larger leaf alphabet the two-value construction gives a lower bound, not the full exact probability. The probability averages over random-oracle setup; for a fixed oracle the existence predicate is already determined. This does not refute the frozen root-resolution implication.

[DERIVED] An observed accepted conflict supplies both paths to the deterministic collision reduction. Verification costs at most `U(k_max+1)` hash calls for `U` unpruned binary openings; finding a collision from the selected depth-`k` pair costs at most another `2(k+1)` if verification work is not retained. No multiplicative root/index loss is necessary. These costs, all adversarial queries and preprocessing belong in the resulting collision adversary's resource bound. The separate `binom(Q+2,2)/N` ROM comparison correctly charges up to two extra queries to check an output collision. A semantic existential path is not such an output. Likewise, resetting a prover that only ever outputs `v0` does not recover a second value merely because one exists.

## Prefix extraction: accepted with these exact premises

[DERIVED] The proposed extractor uses the immutable cumulative query log at each root emission. It follows the prescribed address through first matching node responses and then a typed leaf response, returning a public default if missing. This is efficient per requested coordinate and does not require an honest preimage for the root. The essential invariant is correct: on an unflagged trace, the root query of a later accepted opening was already in the checkpoint, or its later answer would hit the previously declared root. Inductively, each missing child or leaf query would hit a child digest already present in the checkpoint. Response uniqueness forces agreement with the extractor's lookups.

| Contract item | Review conclusion |
| --- | --- |
| Oracle and advice | Two independent uniform typed domains, or injectively tagged equivalent; one consistent lazy cache. Classical code, coins, and auxiliary input must be oracle-independent unless all dependent preprocessing is logged and charged. |
| Trace budget | `q` counts **all distinct inputs**, including honest verification and any preprocessing. A sufficient bound is `q≤q_prover+S(k_max+1)` for `S` unpruned binary verifications. Repeated cached calls do not resample responses. |
| Root budget | `R` bounds all emitted checkpoints on every execution, including adaptively chosen roots. Only roots already declared when a fresh response is sampled are forbidden targets. |
| Failure event | A fresh answer hits a previous answer, an already declared root, or a component of a node input seen by that moment, including the current input. The last clause excludes self-reference. |
| Loss | At fresh query `t`, at most `(t−1)+2t+R` targets are predictable before the uniform response. Summing gives `δ≤min(1,((3q²+q)/2+Rq)/N)`. This is an unconditional adaptive union bound; no conditioning on extraction success is needed. |
| Time and output size | `O(qk)` log comparisons or `k+1` indexed lookups per coordinate. Full extraction also pays for `L` output values and their serialized sizes; retain an implicit word oracle or bound `L` and value lengths when claiming polynomial total time. |
| Challenge timing | Every level word is frozen before its next independent fold challenge. The transparent terminal word is frozen before the independent coherent query sampling required by the ideal theorem. The concrete Fiat–Shamir challenger does not supply this independence automatically. |

[EXECUTED] The independent controls cover all two-value/two-digest functions, depth 0–2, arbitrary prefix query sequences of length 0–2 (including repeats), either root, zero or one arbitrary post-checkpoint query, and every well-sized opening. Of 1,618,176 cases, 809,088 accept and 400,064 disagree with the checkpoint word. Every disagreement flags the trace; 1,728 accepted cases are unflagged, and none of those disagree. These are different and broader cases than the author's 22,016-case accepted-opening control. Also checked 2,145 integer budget identities. This finite falsifier search supports the invariant but does not replace its general proof.

[DERIVED farness] Fix the full sampled hash function and independent prover tape, without conditioning on the good trace. The checkpoint construction then gives a total challenge-prefix strategy, padding aborts with defaults while keeping actual aborts rejecting. Its initial word is fixed before the first challenge. The applicable statement is

`Pr[actual supplied proof accepts ∧ Far_E] ≤ ε_ideal + δ_trace`.

`Far_E` refers to this initial checkpoint word, not the old `Classical.choose` word. Pointwise application of the ideal theorem to oracle/tape choices with `Far_E`, followed by averaging, is valid. Without a relation-to-`Far_E` theorem, unconditional acceptance additionally pays `Pr[¬Far_E]`. The packet explicitly retains this obligation. Computing a coordinate efficiently does not itself prove initial code farness. The `2^-55` ideal term still requires the existing 19-round tower and gap premises with 3603 coherent queries.

Its `x²` fold agrees with a pre-query constant terminal word at five of ten challenge/query pairs. This verifies simultaneous farness and some actual accepted openings in the toy case; it does not inhabit the entire BabyBear instantiation.
