## Exact quantifiers

[SOURCE: game read] The local 2013/727 text, Definition 2, printed p.10,
quantifies over every replacement plaintext in every exposed input slot.
Definition 3, printed p.11, applies that compatibility requirement to function
keys queried both before and after the challenge. Its selective variant chooses
challenge plaintexts before FE setup. For one challenge pair, two slots and
only slot 2 exposed, compatibility for the common gate is precisely equality
for every slot-2 encoding, including the common dummy encoding.

[DERIVED] For a deterministic total gate that rejects unless V(z) and otherwise
returns D_s(z.c), this requirement is equivalent to equality of the decryptor
outputs at every accepted z. An existing accepted signature is in that domain
even if no efficient adversary can find it. The note correctly distinguishes
this premise failure from an efficient recovery algorithm or a scheme break.
An additional perfectly sound receipt relation can change the accepted set;
the argument does not manufacture a proof of a false relation.

[DERIVED] The note's positive selective-MIFE reduction can retain a common,
efficiently sampled auxiliary package while submitting both known candidate
key messages. Its unused-padding-bit inhabitant is valid but hides only unused
syntax, as the note explicitly says. Neither a bit-dependent surrounding HE
package nor an unavailable HE secret key can be supplied by that reduction
without an additional joint argument. These are distinct missing proof steps,
not an assertion that nesting two encryption schemes is always insecure.

[SOURCE provenance] The local 2013/727 title page lists **Shafi Goldwasser,
Vipul Goyal, Abhishek Jain and Amit Sahai**, matching the final author note
pinned above. The paper identifier and definition locations refer to that
four-author local document.

## The selective witness-encryption lead

[SOURCE: definitions and theorem statement read] In local 2024/1477,
Definitions 14–17, printed pp.11–12, give strong puncturing: except with
negligible probability over punctured key generation, no signature verifies
at the punctured message. Punctured-key indistinguishability includes signing
queries on other messages. Definitions 19–22, pp.13–14, give fixed-message
capability encryption, correctness and the selective challenge-tag game.
The displayed game requires t<n, selects the challenge tag and corrupted
positions before signature keys, and forbids challenge-tag signing queries.

[SOURCE: proof step read] Theorem 3 and the opening hybrids, printed pp.17–18,
use the complete assumption suite named by the author note. They replace
honest verification keys with punctured keys before relying on absence of
accepting challenge-tag signatures. This is a substantive change to the
verification-key distribution justified by a source assumption, rather than
discarding hard-to-find witnesses from a universal quantifier.

[DERIVED] The author's n=2,t=1,no-corruption example inhabits this game's
parameter restrictions. A predeclared library of independently encrypted
wrappers can be generated by a one-entry challenge reduction, with all other
wrappers and allowed signatures generated locally. Summing a polynomial
number of such gaps is valid under the stated common auxiliary sampler and
unopened-tag conditions. This gives neither secrecy after that entry opens
nor an adaptively chosen receipt-tag theorem.

[DERIVED] Unlocking a wrapper containing the full FHE secret releases a full
reader. Unlocking a separately proved restricted capability preserves only
that capability's own restrictions. The witness-encryption theorem itself
does not create that restricted capability or an unknown future answer.
