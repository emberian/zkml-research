[SOURCE] The mesh uses length-prefixed Unix sockets. Each custodian exclusively locks its directory. For a new transition it validates the parent QC or pinned genesis, verifies the exact-action grant and operator signature, computes the successor, writes and syncs a single redo WAL slot by temp-file and rename, and syncs the directory. It installs the checkpoint the same way. The actual I/O result enters the kernel. A persistence error terminates the signer. On restart the node redoes the checkpoint from the authoritative WAL before accepting clients. This wrapper restricts fresh epochs to the immediate successor. Equal in-flight digest retries recover the same signed result. [Preparation, persistence and recovery](../native/resident_custody/src/custody_mesh.rs)

[SOURCE] The policy issuer signs a single Learn, Infer, Forget or Migrate including all arguments and the parent head. The head identifies genesis, parent commitment, current state root, epoch, policy, current operator, journal cursor, payment claim and exposure totals. A signs the exercise. For migration, B validates the offer, authenticates acceptance with its own key and obtains a QC binding B and the new claim. The seat payment claim is an opaque digest. Infer charges length in bits and the rank of byte-coordinate projections. Repeated coordinates on an unchanged model add output bits and zero new rank. On a model change, old lifetime totals remain and subsequent coordinates are charged fresh rank. Release requires an actual inference QC, the active operator signature and the node's matching head. Retransmitting an already charged projection discloses the same coordinates. [Node and operator implementation](../native/resident_custody/src/custody_mesh.rs)

[DERIVED] The resident implements one GDN row with eight key coordinates over $p=2^{61}-1$. A step computes $d=\beta(v-Sk)k^T$ and $S'=\gamma S+d$. Replay suppresses a tombstoned write while applying its decay. Orthogonality preserves every later live residual, which makes subtraction exact. ## The opening relation

[SOURCE] The resident circuit proves existence of a 32-byte blind and a cell of the verifier's fixed width such that cSHAKE256 with customization `resident-custody/blinded-cell/v1` hashes their concatenation to the public root, and the selected byte ranges yield the public projection. The verifier supplies the permitted ranges separately. The public cSHAKE customization block uses SP 800-185 bytepad. Every secret-bearing rate block, including the final padding block, runs 24 Keccak rounds in the circuit. Native RustCrypto cSHAKE supplies the independent witness commitment. [Circuit](../native/resident_custody/src/cshake_selective_open.rs) · [NIST SP 800-185, §3](https://csrc.nist.gov/pubs/sp/800/185/final)

[REFUTED: direct Keccak χ gate count] Each of 25 lanes uses one 64-bit AND per round. The full permutation costs $25\times24=600$ packed ANDs or **38,400 bit-ANDs**. Theta, rho and pi are linear. Iota and complement are affine operations using public constants. XORing a public constant into all three shares injects it once under reconstruction. [Circuit schedule](../native/resident_custody/src/cshake_selective_open.rs)

[SOURCE] Minidregg commit `1db75a1dba5d7f1a25867e3654d0a282421db751`, `prover/src/tower256_trace_pack.rs:22,26,37,57`, specifies little-endian Fan–Paar packing, the absolute trace mask, dual basis and coordinate extraction. Here each complete 32-byte witness block is shared in coordinates $\operatorname{Tr}(x\beta_i)$. The implementation builds the trace Gram matrix from the tower relation $y^2+gy+1=0$, then inverts it over GF(2) to recover the canonical Keccak bytes. The partial last block uses ordinary bits. The two opened parties run the same linear map. All 256 basis vectors round-tripped and the absolute trace mask matched the companion implementation. [Trace map and basis test](../native/resident_custody/src/trace_pack.rs)

[SOURCE] Giacomelli, Madsen and Orlandi, §4.1 and Fig. 6, give the three-party Boolean decomposition and the adjacent-pair check. We read the construction, soundness and simulator argument from the local 2016/163 mirror. For parties $p,q=p+1\bmod3$, one AND share is $x_p y_p+x_p y_q+x_q y_p+r_p+r_q$ in GF(2). Summing the three cancels all masks and includes each cross term exactly once. [ZKBoo paper](https://eprint.iacr.org/2016/163)

[DERIVED] The prover commits to all three seeds, inputs, AND outputs and circuit output shares through per-party SHAKE256 view commitments. The Fiat–Shamir input binds the circuit domain and public frame, width, full statement, input corrections, all commitments and all output shares. A fresh 256-bit GGM root derives round/party tapes. The XOR input correction reconciles the three random shares with the trace-encoded witness. The proof opens only maximal subtrees excluding every hidden view, sends the hidden commitment and the second opened party's AND outputs. The verifier recomputes the first party's entire view, both opened outputs, and derives the missing output from the public statement. [Encoding and verification](../native/resident_custody/src/cshake_selective_open.rs)

[DERIVED] For a fixed binding first message for a false statement, all three challenge responses would reconstruct an input satisfying the circuit. At most two trits can succeed. Rejection sampling discards byte 255 before reduction modulo three. Thus the per-first-message bound is $(2/3)^{219}=2^{-128.1068}$. A classical adversary trying $Q$ independent random-oracle challenges gets the usual $Q(2/3)^{219}$ guessing term, plus commitment/collision and primitive terms. This is a classical 128-bit work target for challenge grinding. A tight concrete security reduction for the seed-compressed implementation remains open.

[DERIVED] One 64-byte cell costs $219\times4{,}800=1{,}051{,}200$ transcript bytes for the neighbor's ANDs alone. The measurement identifies the AND transcripts as the dominant cost.
