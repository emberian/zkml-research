Who has the key?

{{GAME_LINK}}{{CREDENTIALS_LINK}}

Our current encrypted learner still has a key that can decrypt its whole memory. The application checks proofs before using that key, but the person holding it can bypass the application.

We want to replace that key with the ability to learn and answer only. That would let an AI keep private internal state even from the person running its computer. Finding a practical way to do this is a central part of the project.
