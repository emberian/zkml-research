# Four effective aggregate coordinates per route

[DERIVED] With a public route s and inferred bits a,b, the fixed feature is
Q=127*e_(4s+2a+b) in 577 ambient coordinates. There are exactly four possible
features per route, spanning rank 4 over the rationals; disjoint routes span
rank 8. Padding does not create additional effective dimensions. The executed
image census in `image_rank_scope.json` separately records which basis members
were actually observed in teacher and test predictions.

[DERIVED] Let z_j be the sum of signed category labels whose inferred pair
maps to bin j among the route's retained 32 contributions. Then C_j=127*z_j.
All other state coordinates are zero. Necessarily z is integer, its L1 norm
is at most the number of retained contributions, and a full window has even
sum parity. These are necessary constraints; they are not a proof that every
such vector is reachable under each particular fixed teaching history.

[DERIVED] An exact score on query 127*e_j is 127*C_j=16129*z_j. Thus the four
exact score functionals have diagonal matrix 16129*I4 on this effective count
state, with determinant 16129^4, and determine every current aggregate
coordinate. A fixed output-key family spanning those functionals would cover
the entire effective aggregate image. Ambient 577D rank-deficiency cannot
support a claim of hidden aggregate coordinates in this specialized feature
map. No such keys are instantiated in this utility experiment.

[DERIVED] The evaluated class prediction is only sign(score), with zero
mapped to +1. Four sign observations need not determine integer magnitudes.
The retained queue and its order are also distinct from the aggregate; exact
aggregate scores do not generally identify the queue. This document is an
image/rank accounting of the chosen utility representation, not the stopped
combined-interface disclosure experiment and not an encryption attack.

[DERIVED] The trusted source process performs the 3B plaintext language
computation. The learner subsequently maintains four recency-weighted label
bins per route. A positive result would show that this public semantic
abstraction helps a restricted history-dependent task. It would not establish
private source cognition, learned neural-state confidentiality, a no-master-read
release mechanism or any new security property of the separate 577D crypto lane.
