# Designated fixed span from honest public setup coins

[HYPOTHESIS pending independent review, 2026-09-07] The existing designated
construction can be generated without ever constructing a scalar master or
delivering scalar projection keys from an initializer. The proposed replacement
uses recipient-owned scalars and an honest public random transcript. This is
a change to initialization, not to encryption, linear continuation or release.
No earlier implementation or frozen proof is changed by this proposal.

## Scope and order

[DERIVED definition] Fix a safe prime p=2q+1 with q odd prime and the
order-q quadratic-residue group G generated by g. Fix an m-by-d public matrix
Y of full row rank over F_q, m<d, before any keys or setup coins. Fix a static
recipient coalition J at this time. Every recipient honestly generates a fresh
dedicated independent scalar a_i uniformly in F_q, publishes A_i=g^a_i, and
retains a_i. The coalition receives its members' scalars. This initial claim
does not cover adversarially correlated recipient registration, extra proofs
of possession, general-purpose key reuse, adaptive registration or a malicious
public randomness source. Group membership and authenticated public identities
are checked under the same separate setup/authentication assumptions as before.

[DERIVED definition] Permute columns using a deterministic public rule so
Y=[Yp Yf], where Yp is invertible m-by-m. Let R=Yp^{-1} and L=-R*Yf over
F_q. For the existing 16-by-577 workload, the first 16 columns are invertible;
the earlier exact integer determinant is -812032080. This proposal uses that
full-rank workload. The separate semantic fixture has rank eight with duplicate
rows and does not satisfy this 16-independent-recipient recipe unchanged.

## Public construction

[DERIVED algorithms] After registration, draw independent public values

```
tau_i <- uniform F_q                  for i=1,...,m
U_j   <- uniform F_p^*                for j=1,...,d-m
B_j    = U_j^2 mod p
H_i    = A_i * g^tau_i
h_free_j = B_j
h_pivot_i = product_l H_l^R_il * product_j B_j^L_ij
```

Publish all tau, U, A, h, Y and group parameters. Anyone can recompute the
entire public construction. The public field elements U are sampled as field
elements, **not** as g raised to sampled scalar exponents. Neither a scalar
master s nor the scalars k_i are computed by the public constructor. Each
recipient can compute its own k_i=a_i+tau_i; that is exactly its existing
projection capability. A coalition of all recipients gets only these m
projection scalars when m<d, subject to the same computational security and
effective-message-image qualifications as the original construction.

[DERIVED correctness] Multiplying the group equations by Y gives
product_j h_j^Y_ij = H_i = A_i*g^tau_i. Thus unchanged honest encryption
C=(g^r,h_j^r*g^x_j) and designated transform give

```
(C_0, product_j C_j^Y_ij / C_0^tau_i)
    = (g^r, A_i^r * g^<Y_i,x>).
```

Fresh encryption coins remain private and independent. Public setup coins
are not interchangeable with these encryption coins. Exact addition and
original-ciphertext expiry retain the prior algebra. Bounded integer decoding
and finality/selected-release limitations remain unchanged.

## Exact joint distribution argument

[DERIVED candidate lemma] Squaring is a surjective two-to-one map from
F_p^* to G, so each B_j is independent uniform in G. Write s_free_j=log_g B_j
only as a mathematical random variable; the algorithm does not compute it.
For fixed recipient a, k=a+tau is independent uniform in F_q^m. The invertible
linear map

```
s_free = log_g B
s_pivot = R*k + L*s_free
```

makes s uniform in F_q^d, independent of a. Equivalently the marginal joint
distribution (s,a,h,A,tau) is exactly the original honest designated setup
with independently uniform s,a and tau=Ys-a. This is a mathematical coupling,
not a claim that s was present in a process memory.

[DERIVED candidate simulation including public roots] Starting with ordinary
fixed-span IPFE h and coalition scalars K_J, use the already reviewed exact
view simulator: draw independent uniform tau; set H_i=product h_j^Y_ij,
A_i=H_i/g^tau_i; give a_i=k_i-tau_i for i in J. The extra public roots are
efficiently reconstructible without any discrete logarithm. For each free
B_j=h_free_j, compute

```
v_j = B_j^((q+1)/2) mod p
U_j = v_j or -v_j mod p, using an independent fair sign
```

Then v_j^2=B_j. Since p is 3 modulo 4, -1 is not in G; v_j and -v_j are the
two distinct square roots. The result is uniform over the two preimages of
B_j, exactly the real conditional distribution. This also covers B_j=1.
Therefore the **full public accepted-coin transcript** has a perfect joint
simulator from the ordinary IPFE view. If this argument is accepted, the
existing fixed-coalition adaptive-input DDH bound carries over with no new
advantage factor, with setup simulation work included in reduction resources.

[DERIVED transcript boundary] The specified public randomness transcript is
the accepted tau and U values. It does not include an operating-system RNG
seed, internal generator state, rejection-sampling tape, or a separate beacon
protocol transcript. Exact uniform sampling is an ideal/expected-time
algorithm convention here. A concrete public beacon or deterministic
hash-to-group realization needs its own bias, unpredictability and transcript
argument. Hashing a public seed to a **scalar** and publishing g to that power
does not implement this unknown-log group sampling requirement.

## What changes and what remains

[HYPOTHESIS pending review] Honest setup would no longer require a private
initializer to hold and erase s or projection-key delivery copies. It would
require honest public group sampling plus recipient-owned secret keys. Public
setup recomputation checks consistency, not the honesty of randomness. An
operator that chooses public U with known logarithms is outside the promise;
the proof does not turn arbitrary malicious software initialization into
master absence. No secure erasure of an unrestricted credential is requested
by the stated honest algorithm because it never computes one.

[DERIVED limitations] The full recipient coalition retains the complete
per-issued-input fixed row span, including expired inputs, regardless of any
software release gate. Matrix kernel dimension alone does not establish
privacy on an encoder's image. The restricted learner is still additive and
classical DDH based. This supplies neither post-quantum security, a hidden
nonlinear learner, selected-answer-only leakage nor an operator-proof process
boundary on the shared machine. Authenticated registration, independent
encryption randomness and continuity resources remain explicit obligations.
